# Rig 0.4.0

Rig 0.4.0 follows 0.3.0. It gives lengths of time a type and adds a date, time, and zone library; makes a parameter with a default an option, given by name; makes `loop` the one loop that gives a value; and adds templates, text over several lines, groups and spreads, and exact objects. It closes the ownership holes found since 0.3.0. Its compiler was rebuilt pass by pass, and `rig check` of Trig takes half the time it took when the rebuild began. **0.4.0 rejects programs 0.3.0 accepted:** each is listed below with its fix, and the last section of [MIGRATING-0.3.md](../MIGRATING-0.3.md) takes a 0.3.0 program to 0.4.0, mostly by script.

## Upgrading

Run the scripts in this order, then `rig check`; [MIGRATING-0.3.md](../MIGRATING-0.3.md), "From 0.3.0 to 0.4.0", says what each rewrites and what it leaves to you:

1. `tools/migrate-durations.py`, once, on 0.3.0 sources: a bare duration is seconds now, where 0.3.0 read nanoseconds.
2. `tools/migrate-datetime.py`: `time.Duration`, `time.Monotonic`, and `datetime.now()`.
3. `tools/migrate-options.py`: an option given by position is named.
4. `tools/migrate-tov.py`: `!` on the time and date calls that can fail.
5. `tools/migrate-loops.py`: `while true` is `loop`; the other loop forms below are flagged.

[CHANGELOG.md](../../CHANGELOG.md), "Upgrading from v0.3.0", gives each rejection's message in full. A form marked *unsound* below built and broke an ownership rule as it ran: it wrote through a read view, lost a write, or read freed memory.

## Rejected now, with the fix

- **Options by name** (`tools/migrate-options.py`):
  - an option given by position, `connect("db", 5432, 5)`, is `timeout: 5`; std's are `base:`, `upper:`, `tailored:`, `scrollback:`, and `DateTime.new`'s clock;
  - `Time.new(8, 30)` is `Time.new(8, 30, 0)`;
  - by hand: `dt.add(span)` is `dt.add(duration: span)`; a default on `_`; a required parameter after an option; a function with options taken as a value (write a closure); a default on a method that meets an API's.
- **Loops** (`tools/migrate-loops.py` rewrites the first and flags the rest):
  - `while true` is `loop`;
  - an `else` on a loop, a `for` or `while` used as a value, and `break v` outside a `loop`: use `loop` with `break v`, `xs.find(f) ?? d`, or `List.index_of`;
  - `loop` as a name, and `file.FileError.loop`, which is `link_loop`.
- **Time** (`tools/migrate-durations.py`, then `tools/migrate-datetime.py`):
  - a bare duration that names a constant of std.time (`time.sleep(5 * time.MS)`) is `ms: 5`;
  - `time.now()` is `time.monotonic()`, `time.Instant` is `time.Monotonic`, `time.unix_ns()` is `datetime.now().unix().ns()`, and the constants `NS` to `MINUTE` are `time.duration(ms: 1)` or a unit's keyword;
  - a reading used as an `Int` is `.ns()`, or `Int(d.ns())`;
  - by hand, each as its message says: `days:` or `weeks:` (`hours: 24`), a negative constant wait, a `Float` known only at run time given to a wait (`time.duration(x)!`), a number given to `time.sleep` through a function value, and a parameter named `ns` to `hours` in a function that takes a `Duration`.
- **Total or visible** (`tools/migrate-tov.py`): `add`, `round`, and `floor` of a `Date`, `DateTime`, and `Instant`, `Monotonic.at` and `add`, and `Duration`'s arithmetic return `!`, and the `checked_` methods are gone.
- **Ownership** (by hand; each message gives the fix):
  - a `Signal[T]` by value: `*Signal[T]`;
  - a view of an actor's value, `!Actor[C]`: the handle's view, `!*Actor[C]`; and `add Actor[T]: G`: delete it, or give the API to the actor's object;
  - `swap` of two `Cell`s (*unsound*): `old = (!c).swap(v)`; and `!s` of a `*{A}` where a `!{A}` goes;
  - a `task.select` arm through a read view of a channel's handle (*unsound*): `+ch`, a handle of your own;
  - a write through a handle in a `[]T` (*unsound*): a write slice, `![]T`;
  - a channel or actor of `T` made in a generic body whose `T` may hold a view (*unsound*): `[T: Owned]`;
  - a write through a write view of a read view, and `for x in !out` where `out` holds a read view (*unsound*): write through the owner;
  - a consuming or write method through `^?T`: own the value, or take a write view;
  - a `defer` that moves an outer binding and assigns it again, or binds several results to new names: a block that owns what it moves;
  - a generic body that discards several results holding a `T`: bind them and drop them.
- **Names:**
  - a name of `if f() as a, b` that reuses a local's or a module-level declaration's;
  - a `for` binding over a chain that hides a local.

  Rename the binding.
- **Other forms:**
  - a write call whose `Bool` value is used, `if !flags.remove(0)`: `(!flags).remove(0)`, or `not` before it;
  - `return f()!` in a fallible `sub`: the call on its own line, then `return`;
  - an object holding another module's generic whose fields name its parameter as an optional: `(?Node)?` or `^Node?`;
  - `$size(T)` alone as a statement: use its value;
  - forms that Zig rejected, each now a Rig error: `&` on a constructor typed by where it goes, `defer defer`, a box where an `Iter` bound goes, and a closure parameter with no type where no function goes.
- **std.http:** a `Response`'s `type` is an `http.Type`: `.png`, or `.other("image/x-icon")`.
- **Built only on `main` since 0.3.0, so no 0.3.0 program meets them:**
  - `extend_from_bytes` and `$embed` records need `obj Name exact` (`tools/migrate-exact.py`);
  - a datetime maker called with constants takes no `!` (`tools/migrate-constant-makers.py`).
- **The command line:** `--release=fast` is gone. Every build keeps Rig's checks; write `--release`, and `+%`, `-%`, `*%`, or `raw` where unchecked code is meant.

`http.serve` also answers 400 to a request whose framing RFC 9112 forbids, and to an HTTP/1.1 request with no `Host` or several, where 0.3.0 served it; it answers 405 to `CONNECT`.

## Language
- **Options and groups:** a parameter with a default is an option, given by name; `..net: Net` makes an object's fields a function's options; `..v` spreads a value's fields into a call; `Point(x: 3, ..p)` updates a copy; `name:` is `name: name`.
- **Text:** backtick templates, `` `{name} is {age}` ``, whose place decides what they become; `"""` and `'''` text over several lines.
- **Loops:** `loop` repeats until a `break`, and `r = loop` ... `break v` gives `v`.
- **Exact objects:** `obj Name exact` holds its fields in declaration order with no padding, for records read from bytes.
- **`$embed(path)`:** a file's bytes as a `Static`, read when the program is compiled; its records are checked as Rig compiles.
- **A failure's trace:** in debug builds, a failure that leaves `main` lists each site it passed.

## Concurrency
- **Select:** a task's end, `done: ?t.on_end()`, and a write view of a channel are arms of `task.select`.
- **Tasks:** `task.all` of tasks that give no value; `task.workers(n)` raises the workers once running; `task.fast_cores()`.
- **Sharing:** `std.shared`'s `Map`, filled and read by several tasks at once; an object of word Cells goes to other tasks.
- **Fork-join:** a fork's record lies in its maker's frame, and a fork its waiter reaches unstarted runs on the waiter's stack. On pup, bench/fork's psum is 6-21% faster than Rayon's and qsort 30-34%.
- **Dense stacks:** a release build gives a task that cannot need much stack 17.6 KB on the Mac, where a large one holds 33.5 KB.
- **Spawn:** 103 ns a task on pup (bench/tasks).

## Standard library
- **std.time and std.datetime:** `Duration` and `Monotonic`; `Date`, `Time`, `DateTime`, `Weekday`, `Instant`, `TimeZone` with IANA 2026f compiled in, and `ZonedDateTime`; `format` checked against its type as Rig compiles. Every call is total or returns `!`, and an oracle compares it with Jiff 1.0.0.
- **Collections:** `!xs.extend(?ys[a..b])` and `!xs.extend_from_bytes(s)`, each growing once; a large embedded table maps without a copy.
- **std.par:** `par.push` writes runs of a Table on several tasks.
- **std.sort:** ipnsort for integers, and pattern-defeating quicksort wherever equal elements are the same value.
- **std.http:** framing by RFC 9112, `Connection` read as a list, `http.ok(<body)`, and a request's text read without a copy.
- **More:** `file.read_link`, `hint.opaque`, and text comparison eight bytes at a time.

## The compiler rebuild
The compiler was rebuilt in place, pass by pass ([docs/internals/rebuild.md](../internals/rebuild.md)). Each step either left the emitted Zig identical or explained every difference. Trig worked at every commit. `rig check` of Trig took 3.95 s and 620 MB at the rebuild's start, the tag `revamp-base`. It now takes 1.95 s and 397 MB, fastest of 7 on burst, a shared x86-64 Linux VM, under load.
- **One type store** for the program: every module interns in it. A type names its symbol by its declaration's ref, and the built-ins are registered once, in module 0.
- **Names keyed by leaf id:** each leaf the parser wrapper makes has an id of its own. The facts about a leaf, and the name it binds, are dense arrays by that id.
- **One constant evaluator** (`cteval.fold`) folds module and local constants, array lengths, compile-time arguments, enum values, and inlining's guards.
- **Sema checks each module once:** byte literals, chains, groups, and loops over iterators are rewritten where typecheck finds them, with what was recorded taken back by a trail.
- **A generic instance is checked once** for the program.
- **Each fact has one recorder and one decider.**
- **LIR:** each module is lowered to a structured IR once it is checked, in place of the storage plan:
  - the ownership checker walks a body's statements and operands from it;
  - the proofs cut a body into units by its regions;
  - frame accounts and the inlining rule count its operations.
- **Emit** reads every storage decision and coercion it prints from the LIR. A temporary made before its statement can act goes into its slot ahead of the statement.
- **The runtime** takes one config record from the program, carries the checkers' classification of each emitted type, and has one checked index and one duration conversion per operation.

## Tooling
