# Rig 0.3.0

Rig 0.3.0 is the first release since 0.2.9. It renames 0.2's types and spellings into the language as it now stands: objects, `@` for self, `^T` boxes, built-in `Map` and `Set`. It adds errors that carry data, APIs, patterns tested with `matches`, fused iterator chains, and `select` as a value. It closes every soundness hole that two audits of the runtime, std, and compiler found. **0.3.0 rejects programs 0.2.9 accepted:** [MIGRATING-0.3.md](../MIGRATING-0.3.md) takes a 0.2.9 program to 0.3.0 one step at a time, mostly by script.

## Upgrading

Run the steps of [MIGRATING-0.3.md](../MIGRATING-0.3.md) in order, and run `rig check` after each:

1. `tools/migrate-0.3.py` makes the renames:
   - `struct` → `obj`, `Box[T]` → `^T`, `Vec` → `List`, `Text` → `String`;
   - self is `@` (`?@`, `@x`);
   - labels are `$outer:`, built-ins are `$size(T)`;
   - a fixed binding is `x =! e`.
2. The spellings no script rewrites, by hand.
3. `tools/state-bounds.py` writes the bounds of public generics.
4. `tools/migrate-std-0.3.py` makes std's renames:
   - `json.parse(?src)!`;
   - `a.order(?b)` for `compare`;
   - one `math.pow`;
   - search takes `?T`;
   - `std.iter` is gone.
5. What the compiler now asks for, most of it with the fix in the message:
   - `tools/migrate-patterns.py` makes patterns bind fields by name (`.rect(:w, h: tall)`);
   - `tools/migrate-matches.py` rewrites `x as .p` as `x matches .p`;
   - `tools/migrate-float-min.py` covers floats, which provide no `Ord`.

[CHANGELOG.md](../../CHANGELOG.md), "Upgrading from v0.2.9", lists every form 0.2.9 accepted that 0.3.0 rejects. A form marked *unsound* there let a program read freed memory.

## Language
- **Objects and self:**
  - `obj` types;
  - methods declare `?@`, `!@`, or `<@`;
  - small objects of integers are one word.
- **Errors with data:**
  - declared error sets;
  - errors that carry fields;
  - `catch` binds as `??` does;
  - a wait fails with the set its work declares.
- **APIs:**
  - a program's own `api Shape`, with `add` for conformance;
  - associated types;
  - API objects (`?{Shape}`, `^{Shape}`, shared and weak);
  - public generics state their bounds.
- **Patterns:**
  - `x matches P`;
  - alternatives that bind when they agree;
  - `name?` and `none` in a payload;
  - fields bound by name;
  - optional fields covered value by value;
  - one path that checks and lowers every form.
- **Iterator chains:** a chain of `map`, `filter`, `zip`, `enumerate`, `collect`, `sum`, `min_by`, … runs as the loop it means. It is typed stage by stage.
- **Values:**
  - frozen values and weak handles;
  - inclusive ranges;
  - optionals that cost nothing where a type has a niche;
  - vectors;
  - owned closures and closures called once;
  - a conditional expression whose condition binds names.
- **Compile time:**
  - compile-time functions;
  - `target.os`, `target.has(f)`, and `target.debug`;
  - `$plain(T)` in generic bodies.
- **Ownership:**
  - a statement's loans end at their last use (CORE §6);
  - a field of an owned object moves as a name does;
  - one rule for assignment, evaluation order, and the views a call returns.

## Concurrency
- **Tasks:**
  - cancellation that passes only down;
  - interrupts (Ctrl-C);
  - task sets and joins;
  - local tasks;
  - a task returned with read loans.
- **Actors:** a panic in an actor's method ends the actor and panics in its caller.
- **Waiting:**
  - `task.select` as a value matched by `match` (`match task.select(add: !a.on_recv(), late: time.after(50 * time.MS))!`);
  - deadlines and parallel loops.
- **Deterministic tests:** `rig test --seeds=N`.
- **The scheduler:**
  - every wait parks;
  - an end wakes only the waits it ends;
  - each worker is on cache lines of its own.

## Standard library
- **Collections:**
  - `Map` and `Set` (ordered) and `HashMap` and `HashSet` (unordered) are built into the compiler;
  - a `Map` or `Set` is one 64-byte cache line.
- **std.io:** the standard streams; a stream splits in two; `File.read` reads into the caller's buffer; `FileError` keeps the system's reason.
- **std.json:** `json.parse(?src)!`, with `JsonError` members that carry offsets.
- **std.text:** a search that tests 16 places at once; `text.Interner`.
- **More:**
  - std.terminal, its memory bounded;
  - std.utf8 as the one owner of UTF-8;
  - BigInt is `Eq + Ord + Hash`;
  - Lemire's `random.int`;
  - `os.exit`, `os.memory()`, `os.on_broken_pipe`;
  - `time.since_start()`;
  - ChaCha20-Poly1305.

## Tooling
- **`rig lsp`:** a language server with diagnostics, semantic tokens, and symbols.
- **Editor grammars:** for VS Code, Vim, and highlight.js, generated from the grammar.
- **`rig test std.NAME`:** runs a std module's own tests.
- **`rig check --tasks`:** lists a program's local tasks.
- **Release builds:**
  - a heap per thread;
  - stack canaries;
  - frame-size warnings;
  - split builds;
  - `--bolt` and `--pgo` (Linux).
- **Diagnostics:** `RIG_HEAP_PROFILE=1` and `RIG_MAP_TRACE=1`.
- **`rig check` speed:** one rework made checking Trig twice as fast, in a third of the memory.

## Verification
- **Rig's full suite:** `swarm test/rig.rip all`, under the sanitizing allocator: 11,440 jobs. They passed once 27 test expectations left behind by two of 0.3's own changes were brought up to date (#938).
  - It covers the test files, every doc example, the examples, the probes, the program matrix, the unit tests, and the reference ownership checker's floors.
- **Trig's full suite on pup:** 1,384 jobs, none died, in 20 minutes. Trig matches tsc on all 12,892 conformance cases, and its symbols and types match the baselines on all 12,884.
  - Trig, a TypeScript checker written in Rig, checks its six cli projects byte-identical to tsc.
- **loco**, the loc port, gives output identical to the Rust loc's.
- **Reviews:** every soundness change of the revamp was reviewed independently, and each review's findings were fixed before merge.
