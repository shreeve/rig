# Syntax review (5 read-only agents, 2026-09-27) — condensed findings
Probes: scratchpad/syntax-review/{symmetry,readability,designer,ux,complete}/

## Designer (done)
Praise: call-site ownership visibility (better than Rust autoref), mandatory capture modes, ?fun borrowed callables, `<p.f` take, diagnostics, generic bodies checked once, "habit may break compile but never change meaning", [ ] vs ( ), `new` shadowing, replace-only Cell.
Coherence breaks: `!` has 6 roles (`=!` inverts it: "fixed"); `-x` drop vs negate depends on line position; `(!s).add()` Bool-returning write receivers ugly; big arrays/structs copy silently (<=8MiB) while refcount needs `+`; SPEC reads like a case list (exception budget).
Push back: (a) generic bodies can't call methods/read fields on T -> blocks std lib (HashMap/iter/fmt); propose per-instance structural method requirements, traits later name them. (b) owning values in containers: Vec[Player w/ Vec field], Vec[Vec[Int]] rejected; ?v[i]/!v[i]/+v[i] rejected for owning elems. (c) second-class borrows: returned borrow borrows ALL borrowed args (not just self); no Vec[?T]; no disjoint write borrows (split_at_mut, !v[0] + read v[1]); no lazy iterator adapters. Suggest `-> ?P from x` provenance. (d) errors: identity by bare name across libs, catch never exhaustive, no payloads; use Zig inferred sets. (e) owned closures take only Copy params (*sub(Event) rejected) — hurts reactive story. (f) closures can't use `!`/`?` propagation; `?` only as fn-return propagation (no optional chaining in main). (g) fallible procedure must be `fun f -> Void!`; `sub f -> Void!` doesn't parse. (h) paren-free: `print f -1` prints f(-1); allow one level only. (j) sigil density ok except `!`.
Gaps: iteration protocol (cheap now: `for` over next(!self)->T?); owned vs view String naming (expensive later; decide now); string building/format; hashing; match patterns (nested, guards, or-patterns `,`, struct destructuring) — reserve grammar; tuples (decide); ranges (..=, step, reverse, 5..0 silently empty); VISIBILITY private-by-default NOW; int types USize/ISize/U128, wrapping/saturating methods; char/Unicode name; I/O: let []U8/![]U8 cross extern; drop bodies on enums/generics; module paths (use a.b, alias, re-export); immutability story; move Signal to userland.
Corners: reserve keywords now (trait impl extend where async await spawn yield when const is); raw pointers = named Ptr[T] not sigil (*T is Rc); Zig ?T/!T inverted vs Rig (friction); name-resolution-based disambiguation (don't add a 3rd); reserve `T!Name` typed errors; effect-annotation grammar (async) as one design; comptime `when` keyword; pub generics state requirements `[T: ==, <]`; error identity by name.
Top10: 1 NOW methods/fields on T in generics (per-instance) + protocol conventions (next/hash/fmt/eq); 2 NOW owned vs view strings naming; 3 NOW owning values in containers + ?v[i]/!v[i]/+v[i]; 4 NOW iteration protocol + ranges as library; 5 NOW reserve keywords/grammar (T!Name, `,` or-patterns, guards, Ptr[T]); 6 NOW private fields by default + module paths; 7 NOW remove `!` overloads (`=!` -> keyword e.g. `fix`/`const`; `sub f()!`; `!`/`?` in closures; `drop x` vs `-x`); 8 LATER borrow provenance/disjoint borrows/Vec[?T]; 9 LATER owned closures with borrowed/owning params; 10 LATER(decide identity NOW) error model + []U8 across extern.

## Symmetry (done) — matrix in agent report; anomalies ranked
1 match breaks sigil rules: bare `match e` + arm `eat(<r)` silently consumes e; `match <e` rejected; `match !e` payloads immutable (even Box). Fix: match ?e / !e (writable payloads) / <e consumes; bare only for Copy.
2 local write borrow `w = !n; w = 5` fails ("expected !Int"), `w += 1` rejected; every other !T binding writes through. Fix: `=` on any !T binding writes through; re-point with `new w = !m`.
3 borrow sigil requirement inconsistent: ?T param needs `?n` even for Int; `?fun` param takes fn bare; held borrows forward bare or with sigil; `self.items.push(1)` in !self rejected; `for x in xs`/`if o as x` on !T binding read-only unless `!xs`. Pick one rule (prefer "lending always shows its sigil").
4 hidden borrows: `for x in v` over Vec[Int] read-borrows v unseen; bare array to slice param rejected; String slices bare `s[0..2]` and `?s[0..2]` both ok, arrays need `?`. 
5 build by name, destructure by position: `.rect(2,3)` rejected; patterns `.rect(h: a)` parse error; positional one-field variant ok but not one-field struct/Box/Cell. Fix: `field: name` patterns + punning; positional one-field ctor for structs/Box/Cell/Signal.
6 `=!` vs `!=` one transposition; `<-` vs `< -` spacing; remove `<-`; respell fixed binding (e.g. `:=`).
7 `-x` drop vs negate by position; `-s.r` field -> misleading numeric error. Fix: `drop x` or restrict.
8 `??` vs `catch` precedence differ (`f() catch 1 == 1` type error); `catch |err|` bars vs `as`; no `if f() as x` for fallible. Fix: catch at ?? precedence, `catch as err`.
9 `sub f()!` parse error; `fun -> Void` dup of sub; `e?` not allowed in sub. Fix: `sub f()!`, reject `-> Void`, `e?` in sub = return.
10 Cell/Signal reject plain data (P, enum, Int?, arrays) Vec accepts. Fix: any Copy T.
11 Cell[Vec] forwards push/pop/clear/len/[i]/get(i) but not swap/fill/copy/for. Complete or drop.
12 Vec of owning elems: ?v[i]/+v[i]/v[i].n all rejected; Vec[*R?] rejected. Allow place borrows.
13 get(i) only on Vec/Cell[Vec]; not arrays/slices/String; no set(i,x).
14 *T vs Box: no way back out of *T (`unshare()` -> T?); positional Box(x).
15 two swaps/replaces (free place fns vs `!s.swap(i,j)`, `c.replace(v)`); `swap(!a[0], !a[1])` rejected. Maybe rename element form `swap_at`.
16 `?p.m()` quietly borrows the result; reject.
17 `?[N]T` plain array param is a copy not a borrow -> can't return slice of it. Lend arrays by pointer.
18 `new` only with `=` (`new x: U8 = 5`, `new x =! 5` parse errors).
19 closure return annotation `|x: Int| -> Int` parse error; fn type `fun -> Int` needs (); `type F = fun(Int)->Int` then `?F` not a borrowed callable (spelling decides).
20 `not !s.ok()` still forced to `not (!s).ok()`.
21 bare `self` receiver rejected (by-value needs <self); no `*self` handle receiver.
22 patterns: no guards, no alternatives, no optional subjects (`match` on Int?), ranges half-open only (`100..256` for U8).
23 enum values `ok = 200` vs module const `=!`.
24 doc contradictions: SYNTAX §15 table lacks * and - columns; App C closure rule omits ? !; DESIGN receivers omits <self; SYNTAX §8 "as bindings immutable" vs writable as/for; LIMIT vs limit const case; memo_canary uses long-form receivers + method named `new`.
25 no `use m as n`; `v.len()` no hint to field; `@sizeOf(Int)` parens vs brackets rule.

## Completeness (done)
Impossible today: `for` over user collection; lending iterator over owning elems; hash arithmetic (overflow panics, `<<` is shlExact, no wrapping ops); string building (no +, no String(bytes), no raw route); number formatting; print without newline / stderr; printing []U8; sort of Vec[*T]/Vec[Box] (?xs[j] rejected); O(1) HashMap with owning V (Vec[*T?]/Vec[Box?]/Vec[Vec]/Vec[OwningStruct] rejected, ?v[i] owning rejected); errors with data; slices of array-backed ?self page; file I/O beyond putchar (extern takes numbers only).
Awkward: hashing in generic (fn-pointer field works), truncating conversion raw only, Vec insert/remove userland via push/swap/pop, HashMap plain K/V open addressing, tests (no assert/panic; `fun expect -> Bool!`), generic struct with drop (not allowed).
Missing: search/split/char literal; Vec cap/reserve/truncate/extend/is_empty/clone; ranges step/reverse/inclusive/values (10..0 silently empty); U8.try, U64.max; abs/sqrt/min/max; optional chaining in main, `?? return`, `if a as x and b as y`, match on optionals; defaults only literals (not LIMIT, Vec(), [n of x]); constants scalar/array only (no struct const, no associated consts); enum values write-only (Int(e) rejected; @intFromEnum not allowed in raw; @enumFromInt allowed); visibility none (`pub` field parse error).
Stops-short: raw only as tail not binding rhs; enum values unreadable; slot borrows in for but not ?v[i]; Vec element rule uneven; as-bindings keep provenance but for-bindings don't (can't `return ?e.v` from for); (?V)? vs (!V)? asymmetric in generics; borrows per root not field path (`for x in ?self.a; self.b += x` rejected; swap special-cased); FN-POINTER FIELD CALL FALSE POSITIVE `self.hash(?k)` in !self ("store a borrow of k in self"); `?xs[0]` of []T param not returnable w/ misleading msg; `?5` -> "expected ?Int, got ?Int"; ?self slices depend on representation; constants ok in array lengths but not defaults; `?` scoped to function; fallible sub no spelling; Box reaches members only of struct/enum; Vec(capacity) unobservable; empty loop body.
