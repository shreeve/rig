Generics now cross module boundaries. A library can export generic functions, generic types, generic methods, and const generics, and importers use them with full per-instance checking.

## Language

- **Generic functions from another module:** `lib.max(3, 7)`, `lib.max[Float](1, 2)`, and `z: U8 = lib.max(1, 2)` (inference from the expected type works across modules).
- **Generic types from another module:**
  - in types: `b: lib.Wrap[Int]` (the grammar now allows a module-qualified generic instance in any type position);
  - in expressions: `lib.Wrap[Int](v: 3)` and `lib.Wrap[Int].make(1)`;
  - generic methods of public types, called from another module.
- **Const generics across modules:** `lib.Ring[Int, 4]`, `lib.zeros[3]()`, and `a: [3]Int = lib.zeros()`.
- **Public surfaces:** a module's public surface may hold instances of its own generic types, such as `pub fun make() -> Wrap[Int]`.
- **Type identity:** `lib.Wrap[Int]` is one type everywhere, whether it is made in main, in another module, or in lib itself, or reached only through a diamond of imports.
- **Chains:** main → lib → util works, and so do the checks through it. A requirement in util's body that main's type argument violates is reported at main's call.

## How it works

- **The library's already-checked SemContext is the export.** The importer makes proxy symbols for the foreign generics and their parameters, always recording the ultimate origin. It copies the library's recorded requirements, ownership plain-data needs, size records, and generic uses. The existing per-instance machinery then runs unchanged.
- **Diagnostics can point into another file.** A failing instance is reported at the importer's call, with a note at the library line that needs the operation. This is the Zig-style contract that DESIGN describes; traits stay on the roadmap.
- **A `pub` generic that nests itself forever is reported where it is declared,** since all its instances would be in other modules.
- **Removed:** every "generics cannot cross module boundaries yet" rejection, and the `pub` array-size rejection.

## Review

- **Two independent reviews:** soundness (about 90 attacks) and front end.
- **Fixed:**
  - a false positive in the declaration-time check (a zip-style method on a `pub` generic type);
  - that check being cubic on long chains (now linear, with a scale test);
  - a method call on another module's generic-enum constant that emitted a call through the type.
- **Also fixed** (these predate this branch):
  - an oversized array argument silently dropped in an inferring generic call;
  - an unused type-parameter discard;
  - a borrowed closure-handle call.
