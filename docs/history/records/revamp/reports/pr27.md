Typecheck used about fifteen overlapping predicates to decide what may be done with a place (`h.w`, `xs[0]`, `self.items[i]`), and each check combined a different subset of them. When they disagreed, code was accepted by one part of the compiler and not handled by another. The most recent case was element write-through: typecheck and ownership accepted it, but emit did not lower it.

## Changes
- **One descriptor and one check.** Typecheck builds one `Place` for each place expression (`placeOf`): its root kind, its steps, and the first read-only step and why. Every check now goes through one `requireAccess(place, access)`, which owns the diagnostics:
  - assignment and compound assignment
  - `!x`
  - `<p.f`
  - `for x in !xs`
  - `Cell.set`
  - element methods
  - swap/replace
  - writing through a held `!T`
- **Removed predicates:** `checkWritable`, `checkSymbolWritable`, `checkLendsWriteBorrow`, `checkUsesWriteBorrow`, `placePath`, `readOnlyPlace`, `copiedBindingRoot`, `cellVecElementIn`, `hasStorage`, `assignsIntoTemporary`, `isStoragePath`, `isFieldPath`, `pathRoot`, `cellSettable` and `placeWritesThrough`.
- **New `writesThrough` fact.** Typecheck records it, and ownership and emit read it instead of recomputing it.

## Behavior
- **Every existing test's diagnostics are byte-identical**, except for two improved hints.
- **Now rejected where two old rules disagreed** (the stricter, SPEC-consistent answer, each with a test):
  - `mk().w = 5` (writing through a `!T` held by a temporary)
  - `!h.w` when `h` is not writable
  - `<mk(!b).r.o`
- **Now accepted:** `|!r|` on an owned `match <e` binding, as `if <o as r` already was.

## Fixes found along the way
- **A crash on accepted code.** A read borrow of a Cell-holding field or element of a temporary was accepted, but the program crashed at run time with a bus error. `Cell.set` wrote through `@constCast` into a struct literal kept in read-only memory. The part is now copied into a mutable local first. This covers call arguments, `?self` receivers and `if`/`while … as` bindings.
- **A compiler panic.** Writing to another module's constant (`geo.KP[0] = 3`, `!geo.KP`) crashed the compiler. It is now a clean diagnostic.
- **Hints that suggested rejected code.** Two hints proposed a fix that is itself rejected (`write !h.w`). They now name what to change, such as `take h: !H`.

- `zig build test` passes.
