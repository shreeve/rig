Phase 1 of the standard library. It adds the mechanism std modules are built on, and the first modules on top of it.

## Mechanism
- **Module paths.** `use std.NAME [as ALIAS]` loads an embedded std module, and `use NAME as ALIAS` aliases a local one.
  - Modules are keyed by qualified name, so a user `math.rig` works beside `std.math`.
  - Std modules are keyed apart from user modules, and may import only other std modules.
  - `RIG_STD=dir` overrides the embedded sources; it is a developer setting.
- **`extern zig "file.zig"`, std only.** Body-less `fun`/`sub` declarations bound to a trusted Zig shim that uses Zig's std.
  - Calls are checked like any Rig call.
  - Each declaration emits a comptime `rig.expectShim` check. A shim whose Zig type differs from the Rig signature fails the build with a Rig message, and the suite calls every declaration.
  - The block is rejected outside std, as are generic and fallible declarations.
- **`main`.** It receives the process's arguments (Zig 0.16 `std.process.Init.Minimal`).
  - `fun main -> Int` (or `-> Int!`) sets the exit status after drops, flushing and the leak check. A status outside 0..255 panics.
  - The four forms `sub main`, `sub main!`, `fun main -> Int` and `fun main -> Int!` share one wrapper with #28's `failMain`.
- **`rig run file.rig -- args`** passes arguments to the program.

## Modules
Documented in the new `docs/STD.md`, with examples the suite runs:
- **std.math:**
  - generic `abs`, `min`, `max`, `clamp`;
  - `gcd`, checked `pow`, floored `mod`, and the constants `PI` and `E`;
  - `sqrt`, `floor`, `ceil`, `exp`, `ln`, `sin`, `cos`, `powf`.
- **std.os:** `args()` and `env(name)`. They return program-lifetime views, bytes as given.
- **std.time:**
  - `now() -> Instant`, with `since` and `elapsed`;
  - `unix_ns()` and `sleep(ns)`, plus unit constants.
- **std.random:** `Rng` (splitmix64).
  - It is move-only, with `fork` for an explicit second generator.
  - `seeded(U64)`, OS-seeded `new()`, `next`, `int(lo, hi)` (unbiased, any range), `float`, `shuffle`.
- **std.sort:** `sort`, `sort_by`, `search` and `lower_bound`.
  - Stable, in place and non-allocating: O(n log n) comparisons, O(log n) stack.
- **std.slices:** `reverse`, `contains`, `index_of`.
- **Vec:** built-in `insert(i, x)` and `remove(i) -> T`.

## Also
- **Ownership fix:** a `!self` receiver of plain data keeps no borrows of its arguments. Previously this wrongly rejected `shuffle(!self, xs: ![]T)`.

## Verification
- `./test/run` passes: 1845 passed, 0 failed, 0 known.
- An independent review found 11 issues, and all are fixed test-first. That includes a `sub main!` regression, `Rng` copies repeating their stream, and std/user module isolation.
- Every accepted reviewer probe runs cleanly, except two deliberate strong-reference cycles, which exit 1 with the leak report as designed.
