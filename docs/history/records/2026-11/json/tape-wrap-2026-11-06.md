# std.json: the tape's arithmetic with wrapping operators (2026-11-06)

The json panel's item 2 (panel/SYNTHESIS.md; zig.md E4a, yyjson.md V4). std.json's tape entries are `payload * 16 + tag`, an open container's entry `len * 2 + kind`, a string's payload `(offset << 27) + length`, and `depth` counts the open containers. Each checked operator costs Zig's overflow test: about 6 instructions per container opened, and as many per string, number, and close.

None can overflow. The input is at most MAX_INPUT (2^32 - 1) bytes, so the tape holds fewer than 2^33 entries, a string's offset is under 2^32 and its length under MAX_STRING (2^27), a small integer is within SMALL_INT (2^59), and `depth` stays under MAX_DEPTH (1,024). So they are written with `*%`, `+%`, `<<%`, `+%=` and `-%=`, which give the same values and check nothing. Position arithmetic (`i + 1`, `i + 8`) is unchanged: that is the panel's item 7, a proofs.zig change.
