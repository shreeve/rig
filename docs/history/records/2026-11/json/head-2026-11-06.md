## The change

`scan_string` tests a string's first 8 bytes inline, one U64 by `special64`, and calls `skip_plain_ascii` only past them (`scan_head`): most keys and short values end there. This is the panel's E3b (zig.md), with SWAR's 8 bytes in place of a 16-byte vector: on arm64 a vector's first set lane costs a narrowing shift, a move, and a count.
