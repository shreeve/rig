# std.json's standing table, Mac (2026-11-05)

The standing table of std.json against yyjson, simdjson, and Go's `encoding/json/v2`, before the v0.3.1 JSON work. The Mac's half; pup's follows when it is reachable.

- **Machine:** the Mac (Apple silicon), load 4.3-7.0 from other sessions' work, under `tools/low`.
- **Rig:** main cf6a362a6. std.json is `rig-safe`, `rig build --release`: Zig's safe mode with every check kept.
- **Harness:** `bench/json/timers/time.py`, MB/s (10^6 bytes), the fastest of 15 interleaved runs of about 400 ms each, with `parse` out of line.
- **The others:** yyjson 0.10.0 and simdjson 3.10.1 DOM, each `-O3 -mcpu=native` (`bench/json/cbench`). Go 1.27.3's `encoding/json/v2` (`bench/json/gobench`, new): `go-v2` unmarshals into an `any`, `go-v2-tokens` reads every token through `jsontext.Decoder` with no tree, and `go-v1` is `encoding/json`, for reference.
