# The per-operation cost, third round: one call per scheduler entry (2026-11-05)

The default-on round's first step, as the foreman approved it on 2026-11-05. The second round (design.md, "The per-operation cost, second round") left task operations 2 to 10% slower with `RIG_PREEMPT=signal`.

## Why the operations were slower

Each scheduler entry outside sched.zig is a call never inlined into the program's code. But sched.zig's own functions called each other through the same names, so the body behind one call made more calls:
- a task's wait went `waitEndApart` → `commitWait` → `parkApart`;
- a task's end went `finish` → `interrupt` → `wakeApart`;
- `spawn`'s body was inlined into the program, with its wake a call.

## Step (a) and (b): each entry is one call

These are now pairs, as `wake` and `park` were, each never inlined under preemption, and each body calls the other entries' bodies:
- `commitWait`, `interrupt`, `interruptForCancel`, `sleepOn`;
- `Waiters.wakeOne` and `wakeAll`, `Done.finish` and `wait`;
- `spawn` and `spawnDetached`.

A wait, an end, a spawn, or an actor's wake is then one call.

Built without preemption, every name is its body. bench/tasks' and bench/actors' `.text` (`objcopy --only-section=.text`) is byte-identical to main 506a291a9's.

Off is the branch without the option; main on is main 506a291a9 with `RIG_PREEMPT=signal`; branch on is this branch with it. Two PGO release builds ran on cores 1 and 11 meanwhile.

- **Left:** spawn's rest is mostly the lock counts (design.md: 6.7 points).

## The section check

test/cli/preempt_section.sh builds bench/tasks and bench/actors with the option. Every instruction in `rig_text` whose debug line lies in sched.zig must belong to an allowed function:
- `current`, `nowNs`, `seed`, `computed`;
- the counted `lock` and `unlock`, `lockGraph` and `unlockGraph`;
- `block`, `unblock`, `leadsOn`;
- `Job`'s `taken`, `free`, `join` and `waitEnd`;
- `settleLeftCalls` and `wakeLeft`.

Main 506a291a9 fails it, since `spawn`'s body (its `destroy`) is inlined into the section; this branch passes.
